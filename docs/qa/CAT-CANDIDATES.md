## 시각 기준

- 실사 사진 스타일
- 정면 착석 전신과 완전한 귀·앞발·꼬리
- 동일한 밝은 웜그레이 스튜디오 배경
- 품종 또는 코트 특징이 후보 라벨과 일치
- 텍스트, 목걸이, 소품, 추가 동물, 잘린 신체, 명백한 해부학 오류, 워터마크 없음

첫 벵갈 생성본은 몸통이 로제트보다 줄무늬로 읽혀 제외했다. 재생성본 `U09`는 어깨·옆구리·몸통·윗다리에 밝은 중심과 어두운 테두리를 가진 분리된 로제트가 명확해 통과했다. 생성 폴더의 선택본 중복과 실패본은 프로젝트 저장 후 삭제했다.

후보와 고해상도 런타임 정체성 생성에는 내장 `imagegen` 경로를 사용했다. 각 후보는 15동작의 실제 자세와 중간 자세를 모두 통과한 뒤에만 GitHub Release 카탈로그에 추가한다.
