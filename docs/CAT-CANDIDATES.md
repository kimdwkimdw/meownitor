# 고양이 후보군

이 문서는 Meownitor용 한국·미국 고양이 20종의 이름과 조사 근거를 기록한다. 엘사는 앱에 기본 포함되고, 나머지는 QA 완료 후 개별 GitHub Release 팩으로 제공한다.

## 앱에서 선택

설정의 고양이 팝업에서 20종의 제작·설치 상태를 확인한다. QA 완료 팩은 필요한 것만 내려받아 선택하며, 삭제하면 Elsa로 안전하게 복귀한다.

## 후보 기준

- 모든 이미지는 동일한 정면 착석 전신 구도, 조명, 배경을 사용한다.
- 털, 눈, 체형, 귀, 얼굴형처럼 작은 화면에서도 구별되는 품종·코트 특징을 우선한다.
- 텍스트, 목걸이, 소품, 배경 장면, 잘린 신체 부위는 허용하지 않는다.
- 고해상도 스프라이트 제작 시에는 각 후보 이미지를 정체성 기준으로 사용하되 배경은 제거한다.
