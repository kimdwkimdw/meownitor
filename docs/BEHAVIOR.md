# 동작 명세

## 용어

- portable: `hw.model`이 `MacBook`으로 시작하는 장비
- iMac: `hw.model`이 `iMac`으로 시작하는 장비
- desktop: 위 두 종류가 아닌 Mac
- external display: `CGGetOnlineDisplayList`가 반환한 화면 중 `CGDisplayIsBuiltin == 0`인 화면
- external keyboard in use: 마지막 key-down이 외장 키보드에서 왔고 10분이 지나지 않은 상태

## 판정 주기

앱 시작 직후 한 번, 이후 5초마다 판정한다. 타이머 지연이 누적 시간을 부풀리지 않도록 한 tick의 가산 상한은 15초다.

## MacBook 규칙

1. 외장 모니터가 있거나 외장 키보드를 사용 중이면 누적 시간을 0으로 만들고 종료한다.
2. 최근 입력이 5분 이상 없으면 누적 시간을 0으로 만든다.
3. 최근 입력이 1분 초과 5분 미만이면 누적 시간을 유지하되 늘리지 않는다.
4. 최근 입력이 1분 이내면 직전 tick 이후 시간을 누적한다.
5. 누적 시간이 25분에 도달하면 큰 경고를 표시하고 누적 시간을 0으로 만든다.

큰 경고는 내장 Mac 화면만 덮는다. 외장 화면으로는 절대 fallback하지 않으며, 클램셸 모드처럼 온라인 내장 화면이 없으면 표시하지 않는다. 왼쪽 위의 macOS 표준 닫기 버튼으로 닫거나 30분·1시간·2시간 중 하나를 선택해 미룬다. 모든 고양이 패널은 첫 `ESC`에서 기존 메시지 영역을 “한 번 더 누르면 닫힘” 안내로 교체하고 2초 안에 두 번째 `ESC`가 들어오면 즉시 닫힌다. 시간이 지나면 원래 메시지로 돌아온다. 미루기 중 외장 모니터 또는 외장 키보드가 감지되면 미루기를 취소하고, 장치를 제거한 뒤 25분을 새로 센다.

## iMac 규칙

- MacBook용 누적 시간은 사용하지 않는다.
- 앱 시작 시 다음 알림을 현재 시각에서 무작위 30~60분 뒤로 예약한다.
- 시간이 되면 300×210pt의 선택한 고양이 알림을 표시하고 다음 알림을 다시 30~60분 뒤로 예약한다.
- 문구는 한국어 `잠깐 쉬면서 몸을 펴주세요.`, 영어 `Take a moment to stretch.`다.
- 외장 화면이 함께 연결되어 있어도 작은 알림은 내장 iMac 화면에만 표시한다.

## 그 밖의 데스크톱 Mac

자세 경고와 휴식 알림을 표시하지 않는다.

## 외장 키보드 판정

- key-down 이벤트만 입력으로 인정한다.
- 앱 시작 시 권한 상태만 확인하며 시스템 권한 대화상자를 강제로 띄우지 않는다.
- 권한이 없으면 작은 앱 내 안내를 한 번 표시한다.
- 권한 안내를 포함한 모든 고양이 UI는 내장 Mac 화면에만 표시한다.
- 권한이 없으면 HID manager를 열지 않고 메뉴에 키보드 감지는 꺼져 있으며 모니터만 확인 중임을 표시한다.
- 설정 또는 메뉴의 `입력 모니터링 설정 열기`를 사용자가 누르면 권한을 요청하고 macOS 개인정보 보호 설정으로 이동한다.
- 권한이 없어도 외장 모니터가 연결되어 있으면 큰 경고를 금지한다.
- `kIOHIDBuiltInKey == true`, transport가 `SPI`, 또는 product 이름에 `Internal Keyboard`가 있으면 내장으로 본다.
- 그 밖의 키보드는 외장으로 본다.
- 내장 키보드 key-down이 들어오면 외장 사용 상태는 즉시 해제된다.
- 마지막 외장 key-down 이후 10분 동안 새 키보드 입력이 없으면 외장 사용 상태가 만료된다.

키 값은 판정에 사용하지 않고 저장하지 않는다.

## 활동 입력

다음 이벤트 중 가장 최근 이벤트의 idle 시간을 사용한다.

- key down
- mouse moved
- left/right/other mouse down
- scroll wheel

## 언어

설정에서 `시스템 설정`, `한국어`, `English` 중 하나를 선택한다. 선택값은 `UserDefaults`의 `appLanguage`에 저장되며 메뉴·설정·알림에 즉시 함께 반영된다. `시스템 설정`은 `Locale.preferredLanguages.first`가 `ko`로 시작하면 한국어, 아니면 영어를 사용한다.

| 위치 | 한국어 | 영어 |
| --- | --- | --- |
| 큰 경고 | 외장 모니터를 연결하고 목을 펴라냥! | Connect another display and sit up straight. |
| iMac 알림 | 잠깐 쉬면서 몸을 펴주세요. | Take a moment to stretch. |
| 미리보기 | 큰 경고와 동일 | 큰 경고와 동일 |

## 고양이 선택

설정에서 기본 엘사와 한국 10종·미국 10종의 설치 상태를 확인한다. 엘사는 기본 포함되고, 추가 고양이는 QA 완료된 GitHub Release 팩을 내려받은 뒤 선택한다. 선택 ID는 `UserDefaults`의 `selectedCat`에 저장되며 메뉴 미리보기, 큰 경고, iMac 휴식 알림과 입력 모니터링 안내에 즉시 함께 적용된다. 저장값이 유효하지 않거나 해당 팩이 설치되어 있지 않으면 엘사를 사용한다.

## 메뉴

- 읽기 전용 현재 상태
- `<선택한 이름> 보기` / `Show <selected name>`
- `설정…` / `Settings…`
- `로그인 시 자동 실행` / `Launch at Login`
- `입력 모니터링 설정 열기` / `Open Input Monitoring Settings`
- `목펴라냥 종료` / `Quit Meownitor`

로그인 항목은 첫 실행에 자동 등록을 시도하며 메뉴에서 해제하거나 다시 등록할 수 있다. macOS 사용자 승인이 필요하면 mixed 체크 상태와 `승인 필요` 문구를 표시한다.
